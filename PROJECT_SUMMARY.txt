   npm install

2. Run Development Server:
   npm run dev
   Open http://localhost:3000 in browser

3. Build for Production:

   - Import in Vercel dashboard
   - Auto-deploys on push
   - Live site ready in 1-2 minutes

================================================================================
DEPLOYMENT OPTIONS
================================================================================

RECOMMENDED: Vercel
  Steps:
    1. Push to GitHub
    2. Go to https://vercel.com/new
    3. Import GitHub repository
    4. Click Deploy
    5. Configure custom domain (optional)
  
  Advantages:
    ✓ Auto-deploys on push
    ✓ Built-in analytics
    ✓ Automatic HTTPS
    ✓ Global CDN
    ✓ Easy custom domain setup

ALTERNATIVE: Netlify
  Steps:
    1. Push to GitHub
    2. Go to https://netlify.com/drop
    3. Connect GitHub repo
    4. Choose deploy
  
  Advantages:
    ✓ Continuous deployment
    ✓ Form handling built-in
    ✓ Easy DNS management

SELF-HOSTED: Your own server
  Requirements:
    ✓ Node.js 18+
    ✓ PM2 for process management
    ✓ Nginx for reverse proxy
    ✓ Let's Encrypt for SSL
  
  See DEPLOYMENT.md for detailed instructions

================================================================================
CUSTOMIZATION GUIDE
================================================================================

Update Brand Colors:
  1. Edit tailwind.config.js
  2. Change colors in theme.extend.colors.brand
  3. Colors are used throughout via Tailwind classes

Update Page Content:
  1. Edit app/page.tsx
  2. Find the section you want to change
  3. Update text, stats, features, etc.
  4. Reload browser to see changes (npm run dev)

Change Fonts:
  1. Edit tailwind.config.js
  2. Update fontFamily in theme.extend
  3. Or use custom Google Fonts

Add Real Screenshots:
  1. Place images in public/ folder
  2. Import Next.js Image component
  3. Replace placeholder divs with Image components

Wire Up Email Signup:
  1. Choose service: Mailchimp, ConvertKit, Sendgrid, etc.
  2. Update form in Final CTA section
  3. Add API integration

Add Google Analytics:
  1. Install: npm install gtag
  2. Add tracking code to layout.tsx
  3. Or use Vercel Analytics (built-in)
