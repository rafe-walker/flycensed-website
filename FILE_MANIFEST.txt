CUSTOMIZATION GUIDE
================================================================================

Content:
  Edit app/page.tsx - Update text, stats, features, pricing, FAQ

Colors:
  Edit tailwind.config.js - Change brand colors in theme.extend.colors

Animations:
  Edit globals.css - Modify keyframes, adjust timing

Fonts:
  Edit tailwind.config.js - Change fontFamily in theme.extend

Layout:
  Edit app/page.tsx - Adjust grid columns, spacing

Adding Images:
  Use Next.js Image component from 'next/image'

Adding Forms:
  Wire up email signup with backend service (Mailchimp, etc.)
